# 🏏 Cricket Player Performance Prediction using AI

## 📌 About the Project

This project uses Artificial Intelligence and Machine Learning to predict how many runs a cricket player may score in an upcoming match based on past performance data.
The system analyzes player form, venue performance, opponent history, and career statistics to give a smart prediction instead of guessing.

---
## 🎯 Project Objective

* Predict player runs using historical cricket data
* Reduce guesswork using data-driven predictions
* Build a simple and interactive web app for predictions

---
## 🛠️ What This Project Includes

* Data cleaning and preprocessing
* Exploratory data analysis (EDA)
* Feature engineering (recent form, venue stats, career stats)
* Machine learning model training
* Model evaluation
* Interactive Streamlit web application

---
## 🚀 How the System Works

1. User enters player performance details
2. Data is processed using saved preprocessing pipeline
3. Model predicts expected runs
4. Result is shown in a simple web app

---
## 🌐 Streamlit Web App

The project includes an interactive Streamlit application where users can:

* Enter match and player details
* Use sliders and dropdowns
* Get instant run prediction
* View prediction history and charts
