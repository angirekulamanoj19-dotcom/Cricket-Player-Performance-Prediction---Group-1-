## Cricket Player Performance Prediction (IPL)
📌 About the Project

Cricket produces a huge amount of player and match data, but many decisions are still made using intuition or simple averages.
This project focuses on using machine learning to analyze IPL player performance data and predict how many runs a player is likely to score in an upcoming match.

The goal is to move from guesswork to data-driven insights that can help analysts, fantasy cricket players, and anyone interested in understanding player performance trends.

## 🎯 What This Project Does

Cleans and prepares real IPL batting data

Explores player performance patterns through visual analysis

Creates meaningful features like recent form and venue impact

Trains machine learning models to predict future runs

Compares a simple baseline with an ML model to measure improvement

Saves the trained model for future use or deployment
